# WALRUS 影片知識庫匯入說明

這份資料包含 3 支教學影片、36 個片段，取自原 HTML 的預置時間軸。
它不是原影片的逐字稿；內容、維修建議與時間點尚未逐項核對原片。

## 建議匯入方式

優先解壓縮 `walrus-knowledge-import.zip`，將 `segments` 內的 36 份 Markdown
文件匯入知識庫。每份文件代表一個片段，內含影片名稱、說明、關鍵字及指定時間連結。
ZIP 是傳輸包，不要假設知識庫平台可以直接匯入 ZIP。

如平台可設定，將每份短文件保留成一個檢索片段；每段約數百字。
若平台仍會再次切分，確認說明、影片名稱與觀看連結留在同一段。
本說明文件不要匯入教學知識庫，以免混入設定內容。

只接受單一文件的平台可匯入 `walrus-knowledge.md`，以 `---` 分隔片段。
API／自行開發的檢索服務可使用 JSON 或 JSONL，將 `content` 作為檢索文字，
其他欄位保留為 metadata；`youtube_timestamp_url` 是回答時應使用的片段連結。
CSV 可用於人工核對或支援欄位映射的平台，並不是所有平台都會自動理解 URL 欄位。

## 回答提示詞

以下內容放到使用知識庫的助理提示詞中：

```text
你是 WALRUS 教學影片查詢助手。只根據檢索到的知識庫片段回答。
依使用者關鍵字、問題與片段內容選出直接相關的片段。
如果只有影片名稱相關，片段內容不相關，不要將該片段列為推薦結果。
每個結果都提供影片名稱、片段主題、開始時間、簡短說明、可點擊的 YouTube 片段連結。
連結必須完整使用該片段的「觀看此片段」URL 或 metadata.youtube_timestamp_url。
不得自行組合影片 ID、推測秒數，或使用其他片段的連結。
多個相關片段可以分列；同一片段不要重複列出。
找不到相關片段時，清楚說明目前知識庫沒有對應內容，不要編造連結。
片段說明來自 HTML 預置時間軸，尚未逐項核對原片；不要稱其為官方逐字稿。
不要把有限的片段說明延伸成未提供的完整維修操作程序。
```
